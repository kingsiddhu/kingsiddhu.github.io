# Siddharth Katabathula

> I build interactive systems across game development, AI, and cybersecurity.

Canonical portfolio: https://siddharthk.is-a.dev/

## Projects

- **Homelab:** A personal self-hosted cloud using Linux, Docker, and networking tools. Services include DNS filtering, reverse proxying, game servers, remote access, automated printing, and LaTeX compilation. [Print-by-email source](https://github.com/kingsiddhu/printer-from-mail).
- **AIDCore:** An experimental personal AI assistant using local LLMs and LangGraph, with file, Spotify, and custom tool integrations. [Source](https://github.com/kingsiddhu/AIDCore).
- **Boids:** A modular 3D flocking simulation in Godot with separation, alignment, cohesion, and obstacle avoidance. [Source](https://github.com/kingsiddhu/boids-godot). [Browser demo](https://siddharthk.is-a.dev/Boids/Boids.html).
- **QACA:** An experimental cancer-information chatbot exploring conversational AI and voice responses for health education. A software prototype, not intended for diagnosis or treatment decisions. [Source](https://github.com/kingsiddhu/ChatBot-QACA).
- **Billify:** A team prototype submitted to RevolutionUC 2026 that explains medical bills using local OCR and redaction before Gemini analysis. Redaction still needs further validation. [Project write-up](https://devpost.com/software/bills-simplified). [Source](https://github.com/kingsiddhu/Billify).
- **HASS:** A MakeUC 2025 team project for finding educational YouTube Shorts by coding topic, using Python, the YouTube Data API, Gemini, and FastAPI. My contribution was frontend and backend integration. [Project write-up](https://devpost.com/software/hass-doom-scrolling-with-a-purpose). [Source](https://github.com/kingsiddhu/HASS).

The portfolio also describes AutoDraft, Retro Dial, and Project Marina. See the canonical portfolio for their current descriptions and concept visuals.
